Layout primitive that arranges its children in a flex row or column with a fixed gap from the spacing scale. Use it wherever items need consistent spacing without hand-picking a gap value.

## Direction

**vertical** — stacks children top to bottom. Default.

**horizontal** — stacks children left to right.

## Gap

**micro** — tightest gap, for label+value pairs and icon-row spacing.

**tight** — paragraph-to-paragraph stacks, label+list groups.

**default** — the default content rhythm; heading-to-body spacing. Default.

**column** — column/grid split gap for multi-column layouts; wider on desktop.
